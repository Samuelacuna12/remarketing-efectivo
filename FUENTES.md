## Cómo leer este registro

- **Consulta completa:** se pudo leer el contenido oficial pertinente.
- **Consulta indexada:** se verificó un resultado oficial indexado, pero la lectura directa encontró una restricción o error. Comprueba el texto completo antes de ejecutar o tomar decisiones jurídicas.
- **Acceso limitado:** se conserva el enlace para revisión desde una sesión autorizada. No se presenta su contenido actual como plenamente comprobado.

La fecha de consulta no significa que se haya realizado una auditoría de una cuenta real ni que la plataforma mantenga sin cambios sus requisitos. Las fuentes regulatorias requieren una comprobación de vigencia y aplicación al caso concreto.

## Qué se debe volver a verificar

Antes de lanzar, comprueba requisitos de cuenta, tamaño activable, retención de listas, opciones de expansión, funciones de exclusión, reglas del canal, permisos y normativa vigente. Después de un cambio de proveedor o integración, repite pruebas de compra, baja, supresión y reintento. Registra qué fuente y versión sustentó la decisión.

Si detectas un cambio, propón una corrección con el enlace oficial y la fecha. No sustituyas una afirmación desactualizada por una captura sin contexto ni por una promesa comercial de un tercero.
